# Customer Segmentation Dashboard

## Overview
This Power BI dashboard analyzes mall customer data to understand spending behavior and demographics.

## Tools Used
- Power BI
- Python (EDA & clustering)
- Dataset: Mall Customers

## Key Insights
- Customers aged 25–40 show higher spending scores.
- High income does not always correlate with high spending.
- Customer distribution across genders is balanced.
